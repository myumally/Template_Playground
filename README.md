## Template Playground

Exercices, tests, et apprentissage des templates en C++.

### Compilation
En ligne de commande dans le terminal :
```g++ main.cpp -std=c++20 -o main```

### Lien utile

bibliothèques actives de parallélisation assistée](https://phd.pereda.fr/assets/thesis/alexis_pereda_thesis.pdf).
